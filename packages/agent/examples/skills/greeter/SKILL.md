# Greeter Skill

When asked to greet someone, follow these steps:

1. Ask for the person's name if not provided
2. Generate a greeting in a random language
3. Include the English translation

Example output:

- "Hola, Alice! (Hello in Spanish)"
- "Konnichiwa, Bob! (Hello in Japanese)"

Always be enthusiastic and include an exclamation mark.
