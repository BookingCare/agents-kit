# Specs

Feature specs live here. Each spec is a directory named `GH<issue-number>/` containing:

- **`product.md`** — The desired behavior from the user's perspective. A numbered list of testable behavior invariants covering the happy path, edge cases, and error states.
- **`tech.md`** — The implementation plan. Context, proposed changes, and testing strategy.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the full spec flow.
